# Alien Reader

Distribuição oficial do Alien Reader para Windows x64, macOS Apple Silicon e Linux x64.

Baixe o instalador em [Releases](https://github.com/obrunodelgado/alien-reader-releases/releases/latest).

Este repositório contém os instaladores, as assinaturas do atualizador e os checksums.
O código-fonte é mantido em um repositório privado separado.

O aplicativo consulta `latest.json` da release estável mais recente. Atualizações
são verificadas por assinatura e instaladas somente quando o usuário escolher.

Instalações antigas que consultavam o repositório privado precisam de uma instalação
manual da versão 0.1.1 ou posterior para receber as próximas atualizações.
